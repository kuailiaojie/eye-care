## 应用名称
护眼助手 (EyeCare)

## 简短描述（200字以内）
护眼助手是一款帮助缓解数字眼疲劳的桌面工具，提供蓝光过滤、屏幕亮度调节和 20-20-20 护眼法则定时提醒。

## 完整描述
护眼助手是一款基于 Windows App SDK 和 WinUI 3 构建的护眼软件，帮助用户在使用电脑时有效保护视力。

主要功能：
• 蓝光过滤 — 屏幕叠加柔和暖色调滤镜，减少蓝光刺激
• 屏幕亮度调节 — 透明遮罩方式降低屏幕亮度，减轻刺眼
• 20-20-20 护眼法则 — 每工作 20 分钟提醒远眺 20 秒
• 长短休息交替 — 短休息与长休息智能交替
• 智能暂停 — 检测到离开电脑时自动暂停计时
• 系统托盘 — 后台静默运行，托盘菜单快捷操作
• 桌面小组件 — 托盘运行时桌面常驻显示使用时长与当前状态，双击打开主界面
• 多显示器支持 — 蓝光覆盖层自动适应每个显示器
• 开机自启 — 可选开机自动启动

技术特点：
• 基于 Windows App SDK 1.6 + WinUI 3 + Fluent Design
• 原生 Win32 互操作，蓝光过滤使用分层透明窗口
• 支持 x64 / x86 / ARM64 三平台
• 无第三方依赖，纯 .NET 8 实现
